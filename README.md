# ANT–PVG Research Observatory

منصة بحث محلية لإدارة موسوعة نظرية الأعداد التحليلية، خرائط المعرفة، الادعاءات، المراجع،
وبوابات مراجعة الأدبيات لمشروعات ANT وPVG/PVFC.

المصدر المعتمد للموسوعة هو مستودع `analytic-number-theory-encyclopedia-ar` (LaTeX + سجلات
النتائج + BibTeX)، لا ملف PDF. أهداف المشروع في [docs/PROJECT_GOALS.md](docs/PROJECT_GOALS.md)، والتفاصيل التشغيلية في [README_AR.md](README_AR.md).

> الحالة: التطوير الفعلي يجري عبر فروع وطلبات سحب. لا تُرفع ملفات PDF ولا قواعد البيانات
> التشغيلية إلى Git؛ يفرض ذلك ملف `.gitignore`.
