# ANT–PVG Local Research Observatory — MVP

منصة محلية أولية تفصل بين ثلاثة مصادر:

1. **ENCYCLOPEDIA** — الموسوعة المرفقة، مصدر داخلي منقح.
2. **MODEL_SYNTHESIS** — معرفة واستدلال غير موثق حتى يربط بمصدر.
3. **LITERATURE** — الأدبيات الخارجية الموثقة.

## التشغيل على Windows

1. فك ضغط الحزمة.
2. تأكد من تثبيت Python 3.10 أو أحدث.
3. افتح PowerShell داخل المجلد.
4. نفذ:

```powershell
python server.py
```

ستفتح المنصة تلقائيًا على:

```text
http://127.0.0.1:8765
```

للتشغيل دون فتح المتصفح تلقائيًا:

```powershell
python server.py --no-browser
```

لإعادة بناء قاعدة البيانات واستيراد الموسوعة من جديد:

```powershell
python server.py --rebuild
```

## الوظائف الحالية

- استيراد PDF المجلد الأول إلى SQLite صفحة بصفحة.
- بحث نصي كامل في الموسوعة.
- سجل ادعاءات مع حالة المصدر والجدة.
- سجل مراجع وحالة القراءة.
- بوابات أدبيات مستقلة.
- قارئ صفحات مستخرجة.
- لوحة قيادة تفصل المصادر الثلاثة.

## قاعدة الحوكمة

لا تتحول أي معلومة من `MODEL_SYNTHESIS` إلى `KNOWN` إلا بعد إسنادها إلى الموسوعة أو إلى أدبيات موثقة.

## ملفات المشروع

```text
server.py                 الخادم المحلي وقاعدة البيانات وواجهات API
static/index.html         الواجهة
static/app.css            التصميم
static/app.js             منطق الواجهة
imports/                  ملفات المصادر المحلية
data/observatory.db       قاعدة البيانات (تُنشأ عند التشغيل)
exports/                  تقارير التصدير المستقبلية
```
