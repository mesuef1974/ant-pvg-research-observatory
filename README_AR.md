# ANT–PVG Local Research Observatory

منصة محلية تفصل بين ثلاث طبقات مصادر ولا تسمح باختلاطها:

1. **ENCYCLOPEDIA** — مستودع «الموسوعة الشاملة في نظرية الأعداد التحليلية»، مصدر داخلي منقح.
2. **MODEL_SYNTHESIS** — معرفة واستدلال غير موثق حتى يُسند إلى مصدر.
3. **LITERATURE** — الأدبيات الخارجية الموثقة.

## المصدر المعتمد

الاستيراد يقرأ **مستودع الموسوعة مباشرة** (مصدر LaTeX + سجلات النتائج + ملفات BibTeX)،
ولا يعتمد على ملف PDF. استخراج النص العربي من PDF يعطي نصًا معكوسًا حرفًا بحرف وبلا
فواصل بين الكلمات، فيتعذر معه البحث نهائيًا؛ أما مصدر LaTeX فهو UTF-8 نظيف ويحمل معه
بنية النتائج ومعرفاتها الثابتة `ANT-*` وحالاتها.

يُحدَّد مسار المستودع بمتغير البيئة `ANT_ENCYCLOPEDIA_ROOT`، وإلا بحث البرنامج في
`D:/analytic-number-theory-encyclopedia-ar` ثم في مجلد مجاور بالاسم نفسه.

```powershell
$env:ANT_ENCYCLOPEDIA_ROOT = 'D:\analytic-number-theory-encyclopedia-ar'
```

## التشغيل

يلزم Python 3.12 أو أحدث، بلا أي اعتماديات خارجية.

```powershell
python server.py
```

تفتح المنصة على `http://127.0.0.1:8765`، ويجري الاستيراد تلقائيًا في أول تشغيل.

```powershell
python server.py --no-browser      # دون فتح المتصفح
python server.py --ingest          # استيراد ثم خروج
python server.py --rebuild         # حذف القاعدة وإعادة بنائها من الصفر
python server.py --root <path>     # تجاوز مسار مستودع الموسوعة
```

## ما يستورده الاستيراد

| المصدر في مستودع الموسوعة | الوجهة في المرصد |
|---|---|
| `manuscript/main.tex` | ترتيب الفصول المعتمد |
| `volumes/**/chapter-*.tex` | جدول `chapters` (26 فصلًا) وجدول `units` (وحدات نصية بحسب الأقسام) |
| بيئات المبرهنات و`\resultid` و`\provedhere` وأخواتها | جدول `results` مع حالة المخطوط |
| `docs/RESULTS_REGISTRY*.md` | حالة السجل وقابلية الاستشهاد لكل معرّف |
| `docs/RESULT_STATUS_POLICY.md` | مرجع الحالات المعتمدة الذي تُقاس عليه بقية الحالات |
| `manuscript/*.bib` | جدول `bib_entries` مع وسم «مستشهد به» |

## ترقيم الفصول

المخطوط 26 فصلًا موزَّعة على 31 ملف مصدر: الفصل السابع مقسَّم على خمسة ملفات
والثامن عشر على ملفين. ولا يُعتمد على رقم اسم الملف لأنه مضلِّل — فملف
`chapter-01-frontiers-map.tex` هو الفصل السادس والعشرون لا الأول. يُستدل على
بداية فصل بوجود `\chapter{}`، ويُرقَّم بترتيب وروده في `main.tex`، وهو الترقيم
الذي يطابق معرّفات `ANT-*-NN-*` في المائتين واثنتين وخمسين نتيجة كلها.

## عرض الرياضيات والبنية

الاستيراد لا يحوّل الفصل إلى نص مسطَّح، بل يفكّكه إلى **كتل مهيكلة** تُحفظ في عمود
`units.blocks` بصيغة JSON: فقرات، ومعادلات معروضة، وقوائم، وبيئات مسمّاة (مبرهنة،
برهان، تعريف، قضية، مبرهنة مساعدة، نتيجة، حدسية، مسألة مفتوحة، ملاحظة، مثال، تمرين).
كل بيئة تحمل معها معرّف `ANT-*` ووسم حالتها، فيظهران بطاقةً في القارئ.

المحصلة من المخطوط: 1227 معادلة معروضة و523 بيئة، منها 103 مبرهنات و147 برهانًا.

الرياضيات تُصيَّر بـ **KaTeX مُضمَّنًا محليًا** في `static/vendor/katex/` مع خطوطه
(نحو 300 كيلوبايت). لا اتصال بالشبكة عند التشغيل ولا CDN. الفقرات العربية تُعرض RTL
والمعادلات LTR، ويُصيَّر 100٪ من التعبيرات الرياضية البالغة 4021 تعبيرًا بلا خطأ.

## البحث

النص يُفهرس عبر FTS5 بعد تطبيع عربي: حذف التشكيل والتطويل، وتوحيد الهمزات
(`أ إ آ ٱ` ← `ا`) والألف المقصورة والتاء المربوطة. يُطبَّق التطبيع نفسه على الاستعلام،
فيتطابق «الأعداد الأولية» مع «الاعداد الاوليه». الترتيب بدالة `bm25`.

## قاعدة الحوكمة — منفَّذة لا موثَّقة فقط

لا تتحول معلومة من `MODEL_SYNTHESIS` إلى `KNOWN` إلا بإسنادها إلى الموسوعة أو إلى
أدبيات موثقة. هذه القاعدة مطبَّقة في `enforce_citation_policy`:

- كل معرّف `ANT-*` يرد في ادعاء يجب أن يكون موجودًا في سجل نتائج الموسوعة، وإلا رُفض الطلب بـ 422.
- ويجب أن تسمح حالته بالاستشهاد (`PROVED-HERE` أو `CITED` أو `CONDITIONAL` أو وسم `CITABLE`)، وإلا رُفض.
- ولا تُقبل حالة `KNOWN` أو `KNOWN-IN-EQUIVALENT-FORM` بلا إسناد أصلًا.

## فحوص تكامل الحوكمة

يُجري الاستيراد فحوصًا آلية على مستودع الموسوعة ويسجل نتائجها في `integrity_findings`،
وتُعرض في تبويب «تكامل الحوكمة»:

| الرمز | الخطورة | المعنى |
|---|---|---|
| `REGISTRY_STATUS_CONFLICT` | حرج | المعرّف يحمل حالتين متناقضتين في سجلين مختلفين |
| `CLAIM_CITES_NONCITABLE` | حرج | ادعاء في المرصد يستند إلى نتيجة لا تسمح حالتها بالاستشهاد |
| `CLAIM_CITES_UNKNOWN_RESULT` | حرج | ادعاء يستند إلى معرّف غير مسجَّل |
| `TEX_REGISTRY_STATUS_MISMATCH` | مرتفع | وسم الحالة في المخطوط يناقض حالة السجل |
| `TEX_ID_NOT_IN_REGISTRY` | مرتفع | معرّف في المخطوط بلا سطر في أي سجل، فهو غير قابل للاستشهاد |
| `CITE_KEY_MISSING` | مرتفع | مفتاح `\cite` بلا مدخل في أي ملف `.bib` |
| `REGISTRY_ID_NOT_IN_TEX` | متوسط | معرّف مسجَّل بلا `\resultid` مقابل في المخطوط |
| `STATUS_NOT_IN_POLICY` | متوسط | حالة لا تتضمن أيًّا من الحالات الخمس المعرَّفة في السياسة |
| `REGISTRY_STATUS_ABSENT` | متوسط | سطر سجل بلا حالة قابلة للقراءة الآلية |
| `TEX_STATUS_MISSING` | منخفض | نتيجة تحمل معرّفًا بلا وسم حالة صريح |
| `UNDECLARED_STATUS_VOCABULARY` | إخباري | وسم حالة مستعمل عمليًا وغير موصوف في وثيقة السياسة |
| `BIB_UNCITED` | إخباري | مدخل ببليوغرافي يظهر عبر `\nocite{*}` فقط |

