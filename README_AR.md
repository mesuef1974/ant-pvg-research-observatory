# ANT–PVG Local Research Observatory

منصة بحث محلية تفصل بين ثلاث طبقات مصادر ولا تسمح باختلاطها:

| الطبقة | المضمون | السلطة |
|---|---|---|
| `ENCYCLOPEDIA` | مادة منقحة من مستودع الموسوعة المحكوم | `INTERNAL_CURATED` |
| `LITERATURE` | أدبيات خارجية بإسناد ببليوغرافي متتبَّع | `EXTERNAL_VERIFIED` |
| `MODEL_SYNTHESIS` | معرفة معيارية وروابط مقترحة وخيوط بحث | `UNVERIFIED_UNTIL_SOURCED` |

أهداف المشروع في [docs/PROJECT_GOALS.md](docs/PROJECT_GOALS.md)، والمعمارية في
[ARCHITECTURE.md](ARCHITECTURE.md).

## التشغيل

يلزم Python 3.12 أو أحدث.

```bash
pip install -e ".[dev]"
```

```bash
alembic upgrade head
```

```bash
uvicorn ant_pvg_observatory.main:app --app-dir backend/src --reload
```

تفتح المنصة على `http://127.0.0.1:8000`، والواجهة تُقدَّم من التطبيق نفسه.
وثائق API التلقائية على `/docs`.

## استيعاب الموسوعة

المصدر المعتمد هو **مستودع الموسوعة نفسه** (LaTeX + سجلات النتائج + BibTeX)، لا
ملف PDF مُصدَّر: استخراج العربية من PDF يعطي نصًا معكوسًا حرفًا بحرف وبلا فواصل
كلمات فيتعذر البحث، بينما المصدر UTF-8 نظيف ويحمل معه البنية والمعرفات الثابتة.

```bash
curl -X POST http://127.0.0.1:8000/api/encyclopedia/import -H "Content-Type: application/json" -d "{\"repository_root\":\"D:/analytic-number-theory-encyclopedia-ar\"}"
```

يسجّل الاستيراد مراجعة Git للمصدر، فيصير كل استيعاب منسوبًا إلى حالة معلومة منه.
وهو متكافئ التنفيذ: إعادته على مصدر لم يتغير تعطي الحالة نفسها.

المحصلة على المستودع الحالي: 26 فصلًا، و416 وحدة نصية، و1227 معادلة معروضة،
و523 بيئة مهيكلة منها 103 مبرهنات و147 برهانًا، و252 نتيجة معرَّفة `ANT-*` منها
237 قابلة للاستشهاد، و104 مداخل ببليوغرافية.

## البحث

فهرس FTS5 على النص المطبَّع للموسوعة ولطبقة المعرفة المعيارية، مع ترتيب بالصلة
عبر `bm25`. التطبيع يحذف التشكيل والتطويل ويوحّد الهمزات والألف المقصورة والتاء
المربوطة، ويُطبَّق على الفهرس والاستعلام معًا فيتطابق «الأعداد الأولية» مع
«الاعداد الاوليه».

مسار البحث في صفحات PDF (`/api/search/pages`) باقٍ بمسحه الخطي: نص PDF العربي
يأتي ملتصقًا بلا مسافات فلا يقبل التجزيء.

## طبقة المعرفة المعيارية

مصدر ثالث في `knowledge/model_synthesis/*.md` خاضع لـ Git: 59 ملاحظة عبر ثمانية
مجالات تضيف ما لا يوجد في المتن بطبيعته — الطريقة والسياق والمحاذير والحدس —
وترصد 13 فجوة تغطية في الموسوعة بالاسم.

**لا يُستشهد بهذه الطبقة**: يرفض `governance.enforce_citation_policy` أي ادعاء
يستند إليها. وحقل `literature` فيها تلميحات بحث غير محققة.

## الحوكمة المنفَّذة

قاعدة الاعتماد الخارجي في `docs/RESULT_STATUS_POLICY.md` بمستودع الموسوعة صارت
قيدًا منفَّذًا يُرجع 422:

1. كل معرّف `ANT-*` في ادعاء يجب أن يكون مسجَّلًا وحالته تسمح بالاستشهاد.
2. ملاحظات `MODEL_SYNTHESIS` لا تصلح إسنادًا بحال.
3. لا تُرفع حالة الادعاء إلى `KNOWN` بلا إسناد.
4. لا ينتقل ادعاء في طبقة `MODEL_SYNTHESIS` إلى حالة موثقة إلا بتغيير طبقته.

والتحديث يُعيد فحص الحالة الناتجة كاملةً، فلا يمكن الالتفاف بترقية الحالة في
طلب وإضافة الإسناد في طلب آخر.

## فحوص التكامل

يُجري الاستيراد 18 فحصًا آليًا ويسجّلها في `integrity_findings`. أبرز رموزها:
`REGISTRY_STATUS_CONFLICT` (حرج)، و`TEX_REGISTRY_STATUS_MISMATCH` و
`TEX_ID_NOT_IN_REGISTRY` و`CITE_KEY_MISSING` (مرتفع)، و`STATUS_NOT_IN_POLICY`
(متوسط)، و`MODEL_NOTE_COVERAGE_GAP` (إخباري).

## بوابات الأدبيات وسجل المراجع

سجل مراجع المرصد مستقل عن ببليوغرافيا الموسوعة، ولكل مرجع حالة قراءة:
`DISCOVERED` ← `ABSTRACT-READ` ← `FULLY-READ` ← `VERIFIED`. ويجوز وصله بمدخل في
الموسوعة عبر `bibliography_key` فلا يُكرَّر التوثيق.

المراجع تُربط بالبوابات بعلاقة صريحة: `COVERS` أو `PARTIAL` أو `ADJACENT` أو
`CONTRADICTS` أو `NOT-RELEVANT`. **البوابة بلا مراجع مربوطة سؤال بلا مسح**،
وحكمها حينئذ رأي لا نتيجة مراجعة.

ولذلك تُنفَّذ قاعدة إغلاق:

- لا تُغلق بوابة بحكم `NOT-ASSESSED`.
- الحكم `KNOWN` أو `EQUIVALENT` يقول إن المسألة موجودة في الأدبيات، فيلزمه مرجع
  مربوط بعلاقة `COVERS` وحالته `FULLY-READ` أو `VERIFIED`. الاطلاع على المستخلص
  لا يكفي لإسناد حكم.
- الحكم `NOT-FOUND-YET` لا يستوجب ذلك بطبيعته — **ولا يعني جِدّة**: هو واقعة عن
  مسحنا لا عن العالم.

## حماية الطبقة البحثية

قاعدة البيانات مُشتقّة في معظمها: الفصول والنتائج والببليوغرافيا تُعاد بناؤها من
مستودع الموسوعة متى شئت. لكن **الادعاءات والبوابات والمراجع وأحكامها وروابطها
تُدخَل يدويًا**، ولا توجد إلا في ملف قاعدة غير متتبَّع في Git.

لذلك تُصدَّر هذه الطبقة إلى `exports/research-layer.json` وهو **متتبَّع عمدًا**:

```bash
python scripts/research_layer.py export
```

```bash
python scripts/research_layer.py import
```

التصدير حتمي تمامًا: الترتيب مثبَّت، والمعرفات الرقمية مستبعدة، والروابط بالمفاتيح،
**ولا طابع زمني في الملف إطلاقًا** — لا طوابع الإنشاء والتحديث ولا تاريخ التصدير نفسه،
فتاريخُه يسجّله إيداع Git ووضعُه في الملف كان سيُنتج فرقًا يوميًا بلا تغيّر في المحتوى.
فتشغيله مرتين على قاعدة لم تتغير يعطي الملف نفسه، وتعكس فروق Git تغيّر البحث وحده.

والاستيراد استرجاع ودمج لا مزامنة تدميرية: يُحدِّث الموجود، ويُنشئ الناقص، **ولا
يحذف ما يغيب عن الملف**. ويميّز في تقريره بين ما تغيّر فعلًا وما كان موجودًا بالقيم
نفسها، فلا يُوهم بتغيير لم يقع. ويتخطّى الروابط المعلَّقة بدل الفشل. والصيغة موسومة بنسخة،
فالملف الأقدم يُرفض صراحةً لا يُقرأ خطأً.

وللقراءة من الواجهة: `GET /api/research-layer/export`. الاسترجاع يبقى على سطر
الأوامر لأنه يكتب في القاعدة.

## شبكة الروابط

`knowledge_links` تربط كائنين بنوعٍ ومفتاحٍ نصي لا بمفتاح أجنبي، لأن الأنواع
متغايرة (نتيجة، ادعاء، بوابة، مرجع، ملاحظة معيارية) ولأن الرابط قد يسبق وجود
الطرف الآخر. مثال: `claim/CLAIM-0001 —DEPENDS-ON→ result/ANT-THM-06-01`.
